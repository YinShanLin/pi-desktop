Style F · 设计决策

底色
#1a1a1f（带蓝紫调灰，非 pure-black）
sidebar bg
#232329（比主底亮 1.7%，靠这一档做层级）
主区 bg
同底色，不画框，靠 padding 撑空间
active row
accent-soft 染色（不是灰），跟品牌色一致
字体
14.5px ui / 12.5px mono caption，5 级 scale
圆角
最大 10px（composer 容器），其他 4-6px
session row
title 加粗 12.5px + meta 行 10.5px mono，复用颜色梯度
send 按钮
accent 实色背景 + 白字 + 内嵌 ⏎ arrow chip
右栏
默认隐藏；按 ⌘. 唤起，Context / Files / Changes 三 tab
session pill
圆角胶囊，Session · title · ▾，点开 → ⌘K 切换

与现状的差异

  • 顶栏不再裸露：从左侧 traffic-light 直接开始，sidebar toggle 作为第一个 icon；中间放 session pill 胶囊，右侧 3 个 icon button
  • sidebar 始终有视觉差异：折叠态是 48px icon-rail（与主区同底色）；展开态下沉到 bg-1，与主区形成 1.7% 亮度差
  • active row 用品牌色：不是灰色 bg-3，而是 accent-soft，accent 文字——能"一眼看到"当前在哪
  • send 按钮变实色：从"灰色 ⏎ 提示"变成带 ⏎ chip 的 accent 主按钮，可点击目标大 24×
  • 右栏有内容：当前文件 / token 进度 / 改动文件 / 工具调用记录——不再是空架子
  • caption 用 pill：model / cwd 用 999px 圆角胶囊，跟 session pill 视觉一致，整体节奏更顺

交互节奏

  • 顶栏所有按钮 32×32 实心触控区
  • sidebar 折叠/展开 200ms ease-out
  • composer focus-within 边框由 var(--border-2) → accent，110ms
  • active session pulse 1.2s 呼吸
  • 右栏唤起从右侧 200ms slide-in
